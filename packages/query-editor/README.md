# QueryEditor Component

QueryEditor is a React component for querying and viewing results

## Installation (pnpm)

```sh
# peer dependencies
pnpm add @tabler/icons-react
pnpm add @millenniumdb/driver
```

```sh
# component
pnpm add @millenniumdb/query-editor
```

## Usage

Ensure you have Mantine's core and query editor styles imported in your app root:

```tsx
// in your app entry point
import '@millenniumdb/query-editor/styles.css'
```
